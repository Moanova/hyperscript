# Hyperscript :: Vision produit


## Hyperscript : Un éditeur visuel de carte narrative pour les auteurs de fiction moderne.
- **Description**:
    Hyperscript est l’outil qui permet aux scénaristes de jeux vidéo, de micro-séries ou d’autres formes de fiction moderne de
      - construire visuellement leurs cartes narratives sans compétences techniques,
      - gérer les embranchements et les arcs narratifs avec une vue claire des liens entre éléments,
      - exporter leurs travaux dans des formats universels pour collaborer avec leurs équipes (développeurs, réalisateurs) sans opérations manuelles.
    Pourquoi ?
    Les logiciels de traitement de texte classiques sont inadaptés, tandis que les outils professionnels spécialisés s’avèrent souvent trop complexes ou trop coûteux. 
    Les solutions existantes ne répondent pas complètement aux besoins des auteurs de fiction moderne, en particulier les créateurs indépendants. 
    1. Flexibilité : adapté aux récits complexes et non linéaires.
    2. Simplicité : interface intuitive zéro code pour se concentrer sur la structuration des récits.
    3. Collaboration : partage simplifié avec les équipes via des exports directement exploitables.
    En une phrase, Hyperscript est le couteau suisse visuel des scénaristes indépendants pour structurer des récits complexes sans se perdre dans la technique.
