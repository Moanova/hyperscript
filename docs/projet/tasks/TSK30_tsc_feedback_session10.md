## Décisions actées (séance 10, TSC)

1. **1.1** : à la création et à l'ouverture d'un projet, la vue active est **« Agents »** (révise la décision TSC28 « vue par défaut inchangée : Journeys ») ; `04_interface` §3 FR/EN à mettre à jour.
2. **2.1** : placement d'une nouvelle carte agent = **première cellule libre de la grille invisible en scan row-major depuis (0, 0)** (coin haut gauche) ; l'espace de travail de la vue « Agents » n'est **extensible que vers la droite et le bas** (clamp de l'expansion de scène à `left/top ≥ 0` ; le clamp des cartes via `sceneRect` suit).
3. **3.1/3.2/3.3/3.6/5** : la matrice « Relationships » adopte le pattern planoscript — `setAlignment(AlignLeft | AlignTop)`, scène `(0, 0, 4000, 4000)` croissant droite/bas uniquement, **ascenseurs toujours visibles** (`ScrollBarAlwaysOn`, comme Journeys/Agents/matrice planoscript), grille dessinée sur **tout le viewport visible** (lignes snapées sur la grille de cellules 100 px, `_GridLineItem` non interactif à boundingRect réelle), redessin sur scroll (`valueChanged`) **et** resize, `self.view.setMinimumSize(0, 0)` pour que le layout ne relève pas le minimum de la fenêtre ; **dimensions des cellules conservées à 100×100** ; **point au centre de chaque cellule** façon vue Agents (`agents_view_dot_radius_px` / `agents_view_dot_color`).
4. **3.4** : `QToolTip.showText(event.screenPos(), self.toolTip())` sans 3ᵉ argument (pattern `base_node.py:406`) + `hoverLeaveEvent` → `QToolTip.hideText()`.
5. **3.5** : hit-testing corrigé par `mapFromScene` — `card.shape().contains(card.mapFromScene(pos))` (idem `_cell_at`) ; tests offscreen renforcés avec de vrais événements souris (press/move/release via `mapFromScene`), à valider sur le poste de dev.
6. **3.7** : cellule = **case à cocher** façon `MatrixCheckItem` de planoscript (taille/couleurs en config, clés `agents_view_checkbox_*` ajoutées au `config.json`) ; le symbole coché est un **cercle de fond plein toujours de la même couleur (or)** — couleur fixe en config (ex. `relationships_view_check_color`, or `block_scene_color` #E5C07B), **pas** la couleur du type ; le **type de relation apparaît au survol dans l'infobulle** de la cellule (le tooltip existant `setToolTip(note)` est complété avec le type). **Clic gauche sur cellule vide → création directe d'une relation de type « Undefined »** (déjà en tête de `relationship_types`, TSK28) via `CreateRelationshipUseCase` (paire ligne/col + bloc d'ancrage courant), sans dialogue ; clic gauche sur cellule remplie → dialogue d'édition pré-rempli (comportement TSK29 conservé) ; **clic droit → menu contextuel** (RG055, comportement TSK29 conservé).
7. **3.8** : séparateur visuel (`QFrame` en `HLine`, couleur `border_color`) entre la combo du filtre Agent et le label « Blocks » du panneau latéral.
8. **4.1** : la combo Journey du panneau latéral émet l'**id du parcours choisi** (`Signal(object)`, `None` = « All journeys ») ; côté `MainWindow`, choisir un parcours → `activate_journey_usecase.execute(journey)` + filtre activé (comme `_activate_journey`, `main_window.py:853`) ; « All journeys » → filtre désactivé. Synchro Display > Journey conservée via `_rebuild_journey_menu()`.
