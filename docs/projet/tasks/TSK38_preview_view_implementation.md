## Plan d'implémentation

1. **Service Qt-free** `src/core/services/preview_service.py` (nouveau) :
   - `build_preview_html(project, narrative_map, journey=None, agent_id=None) -> str` : sous-ensemble HTML 4, contenu échappé (`html.escape`) ;
   - sections a)–g) : a) projet `lb` ; b) liste des agents (ancres `#agent-<id>` vers g) ; c) carte `lb` ; d) liste des parcours (ancres `#journey-<id>` vers e) ; e) par parcours : blocs depuis Start dans l'ordre `JourneySequenceService` (RG044), chaque bloc `lb`/`typ`/`content` (note en infobulle via ancre `#note-block-<id>`), transitions en ligne, conditions sur leur branche, **relations ancrées sous le bloc** (lb agents 1 et 2, `typ`, `content`, note) — état des relations dans e), pas de section finale ; branches non jointes au Start restituées après le flux, marquées, regroupées par chaîne ; f) orphelins (aucune transition entrante ni sortante) ; g) agents du projet `lb`/`typ`/`content` (note) ;
   - filtres : `journey` = parcours actif si filtre de parcours actif, sinon tous ; `agent_id` = filtre agent (RG063 : blocs de participation, transitions visibles, relations dont le bloc d'ancrage est visible ; intersection RG064) ; hors filtre = omis du rendu ;
   - `build_note_index(...)` pour les infobulles ;
   - **jamais de `set_modified`** (read-only, RG058).
2. **Vue** `src/ui/views/preview_workspace.py` (nouveau) : `PreviewWorkspace(QTextBrowser)` — read-only, `setOpenLinks(False)`/`setOpenExternalLinks(False)`, ancres internes = scroll passif (`scrollToAnchor`), notes en infobulle (`anchorAt` + `QToolTip.showText` + index des notes), stylesheet sombre explicite (fond `bg_primary`), placeholder « Aucun projet ouvert » ; `refresh_preview(project, map)` régénère via le service.
3. **Intégration** `src/ui/main_window.py` + `src/ui/widgets/tab_bar.py` :
   - onglet « Preview » dans la `TabBar` + page `QStackedWidget` = `SidePanelSplitter(PreviewWorkspace, FiltersSidePanel(show_block_list=False))` au niveau page (comme Journeys, TSK33) ;
   - renommage `menu_actions['view_export']` → `menu_actions['view_preview']`, entrée « View › Preview » **activée** (bascule sur l'onglet) ; `export_map` reste grisé (FN013) ;
   - panneau latéral câblé sur les mêmes signaux que Journeys (`journey_filter_requested`/`agent_filter_requested`), état des filtres possédé/partagé par MainWindow et poussé à tous les panneaux (`set_journey_filter_active`/`set_agent_filter`, `_resync_filter_panels` inclut le panneau Preview) ;
   - régénération : à chaque bascule sur l'onglet (`_on_tab_changed("Preview")`) **et** après chaque modification du modèle si la vue est active (signal de modification existant, ex. `workspace_modified`) ; jamais en arrière-plan ;
   - la visualisation et les filtres ne marquent ni carte ni projet modifiés.
4. **Tests** :
   - unitaires Qt-free du service (`tests/test_preview/test_preview_service.py`) : sections a)–g), ordre RG044, filtres RG063/RG064 (parcours actif / Tous / agent), orphelins, branches non jointes au Start marquées, relations sous leur bloc d'ancrage, échappement HTML, non-modification ;
   - offscreen (`tests/test_preview/test_preview_workspace_offscreen.py`) : onglet « Preview » présent, panneau latéral présent (sans liste de blocs), régénération à la bascule et sur modification si actif, lecture seule (liens inertes), menu View › Preview renommé et activé, `export_map` toujours grisé.
5. **Docs à l'issue** : matrice `implementation-FR/EN.md` SU010/FN033 → `implemented` ; kanban ; SESSIONS.md.
