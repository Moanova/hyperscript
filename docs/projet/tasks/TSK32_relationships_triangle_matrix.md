# TSK32 — Re-conception de la vue « Relationships » : matrice triangle supérieur + carte Relationship dans la case

- **Statut** : Review (20-11-2026) ; dépend de #TSK31 (Done), #TSK33 (Review). Conception actée séance 10 (voir SESSIONS.md).
- **Origine** : la matrice symétrique affichait **2 coches par relation** (confusion actée par TSC, séance 10). Re-conception complète actée : **matrice agent×agent en triangle supérieur** avec **carte Relationship matérialisée dans la case**.

## Conception actée (séance 10, TSC — voir SESSIONS.md pour le débat)

1. **Matrice triangle supérieur** : lignes et colonnes portent les **mêmes agents** avec **un seul ordre partagé** persisté (`relationships_view_agent_order`, migration depuis `row_order`/`column_order`) ; la diagonale est neutralisée (pas d'auto-relation, RG035) et le **triangle inférieur est vide/estompé et non interactif** → exactement **une case active par paire** (i < j dans l'ordre partagé). Cela résout le doublon symétrique ET la question combinatoire (RG035 borne les relations affichées à N(N−1)/2 pour N agents ; la taille de la matrice ne dépend que de N). Le déplacement d'une carte d'en-tête réordonne **ligne et colonne simultanément** (un seul ordre).
2. **Carte Relationship dans la case** : la case active contient une carte (géométrie en config ~84×72 dans la cellule de 100 px) — bordure **#E06666** (couleur Pivot/Condition, clé config dédiée `relationships_view_card_border_color`), libellé = **type** de la relation, extrait de note ; infobulle RG054 = type + paire + bloc d'ancrage + note. Position dérivée de la case, jamais persistée. Au plus une carte par case (état dérivé au bloc sélectionné, RG069 + RG035).
3. **Interactions** : **pas de clic gauche dans les cases** (la création rapide « Undefined » de TSK30 est abandonnée) ; **clic droit seul → menu contextuel RG055** : case vide → « New... » avec dialogue pré-rempli (paire + bloc sélectionné) ; case remplie → « Edit... »/« Delete... » de la relation de la case + « View in Journeys view » (FN032). Le menu contextuel est actif aussi sur les **cartes d'agent** (en-têtes) : « New Relationship... » (agent pré-rempli) + édition/suppression des relations de l'agent.
4. Post-MVP (plusieurs relations par paire si RG035 levée) : empilement de cartes dans la case à prévoir — non traité ici.
